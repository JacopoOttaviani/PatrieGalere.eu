Sul progetto

PatrieGalere è un progetto open source fatto da Jacopo Ottaviani basato sui dati di Ristretti Orizzonti.

Il progetto iniziale fu programmato a mano nel 2011, pubblicato sul Fatto Quotidiano in Italia e The Guardian nel Regno Unito, e identificato come il primo progetto di data journalism italiano.

Oggi, il progetto è riproposto con tecnologie nuove e un design rivisto, ma sempre aderente ai principi degli open data e della tecnologia civica.

Fonti

Ristretti Orizzonti è una rivista e centro di documentazione sul carcere, attiva dal 1999 a Padova. Raccoglie e pubblica dati sistematici sui decessi negli istituti penitenziari italiani, ed è uno dei principali osservatori indipendenti sul sistema carcerario in Italia.

Tecnologie

Leaflet — libreria open source per mappe interattive.

Chart.js — libreria per la visualizzazione di dati con grafici.

PatrieGalere is an open source project by Jacopo Ottaviani based on data from Ristretti Orizzonti.

The original project was hand-coded in 2011, published in Italy's Il Fatto Quotidiano and The Guardian in the UK, and identified as Italy's first data journalism project.

Today the project is revived with new technologies and a revised design, while remaining true to the principles of open data and civic technology.

Sources

Ristretti Orizzonti is a magazine and documentation centre on prisons, active since 1999 in Padua. It collects and publishes systematic data on deaths in Italian penitentiaries, and is one of the main independent observers of the Italian prison system.

Technologies

Leaflet — open source library for interactive maps.

Chart.js — library for data visualisation with charts.
